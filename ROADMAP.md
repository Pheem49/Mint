# Mint Roadmap

This roadmap describes the direction of Mint. It is a planning guide, not a promise of delivery dates. Priorities can change as contributors and users provide feedback.

## Now

- Make the first-run path reliable across Linux, macOS, and Windows.
- Publish verified prebuilt CLI binaries and keep source installation available.
- Improve the GitHub landing page, demo, onboarding, and troubleshooting docs.
- Make the Telegram and messaging workflow a clear, dependable coding-agent experience.
- Add small, well-scoped issues that new contributors can complete without learning the whole codebase.

## Next

- Expand release coverage for more CPU and operating-system combinations.
- Improve setup diagnostics for providers, messaging bridges, optional tools, and permissions.
- Add focused examples for coding tasks, scheduled work, MCP tools, and local models.
- Improve contributor documentation and test coverage around the shared agent harness.
- Gather feedback through GitHub Discussions and turn repeated requests into design notes.

## Later

- Make the desktop, web, CLI, and messaging surfaces feel more consistent.
- Improve observability for long-running agent tasks and gateway deployments.
- Grow the skills and plugin ecosystem with clearer packaging and discovery.
- Evaluate additional sandboxing and deployment options for always-on agents.

## How to influence the roadmap

Open a [Discussion](https://github.com/Pheem49/Mint/discussions) for an idea or question. Use an [Issue](https://github.com/Pheem49/Mint/issues) for a reproducible bug or a scoped implementation task. Small, concrete proposals with a clear user problem are easiest to evaluate.
